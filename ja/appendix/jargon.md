# 付録 B　設計現場の言い回し

IC 設計チームの日常会話には、独特の言い回しがたくさんあります。たとえば「このパスの slack が大きく負けてるから、真ん中で一段切ろう」。チームに入ったばかりの人は、初めて聞くと戸惑うことがよくあります。

この付録では、IC 設計の現場でよく聞く言い回しを例文とともにまとめます。2 列目は台湾のチームでの言い方で、中国語と英語の用語が混ざって使われています。台湾の同僚と仕事をするときに役立ちます。言い方は会社やチームによって違うので、ここでは広く使われるものを挙げています。正式な定義は[付録 A　用語集](glossary.md)を参照してください。

---

## フローと日程

| 言い回し | 台湾のチームでは | 意味 | 例文 |
|---|---|---|---|
| spec | spec | 仕様書 | 「spec は飽和なのに、なんで RTL はラップアラウンドになってるの？」 |
| フリーズ | freeze | 凍結。以降は勝手に変えられない | 「RTL フリーズのあとは、どんな変更も ECO を通すこと」 |
| テープアウト | 下線、tape-out | 設計をファウンドリに渡す | 「来月テープアウトだから、今週で signoff を片付けよう」 |
| シャトル | shuttle | MPW の便 | 「このシャトルに乗り遅れたら、さらに 2 か月待ちだ」 |
| サインオフ | signoff | ある確認が正式に通る | 「DRC はサインオフ済み。残りは IR だ」 |
| フロントに差し戻し | 打回前段 | RTL まで戻って直すほど大きな問題 | 「ここまで足りないなら、フロントに差し戻してアーキテクチャから直すしかない」 |

## フロントエンド設計

| 言い回し | 台湾のチームでは | 意味 | 例文 |
|---|---|---|---|
| インスタンス化、インスタンス | instantiate、instance | モジュールの実体を置くこと。その実体 | 「トップで `mac` を 64 個インスタンス化している」 |
| lint をかける | lint 一下 | Lint で書き方を調べる | 「合成に回す前に lint をかけておいて」 |
| ラッチができる | 長出 latch | 論理合成で思いがけずラッチができる | 「`case` に `default` がないから、ラッチができた」 |
| 最適化で消える | 被 optimize 掉 | 論理合成ツールに削られる | 「このレジスタ、最適化で消えてるよ。出力がつながってない」 |
| CDC を通す | 過 CDC | クロックドメインをまたぐ信号をシンクロナイザで扱う | 「`START` はバス側から来るから、CDC を通さないと」 |
| メタる | meta | メタステーブル | 「1 段目の flop はメタるかもしれないから、直接使わないで」 |

## 検証

| 言い回し | 台湾のチームでは | 意味 | 例文 |
|---|---|---|---|
| TB | TB | テストベンチ | 「まず TB をつないで、smoke test を流そう」 |
| smoke test | smoke test | 大きな問題がないかを見る、最も基本的で速いテスト | 「smoke test も通らないなら、regression はまだ流さないで」 |
| ゴールデン、ゴールデンモデル | golden、golden model | リファレンスモデル | 「RTL がゴールデンと合わない」 |
| regression を回す | 跑 regression | リグレッションテストを流す | 「今夜の regression で三つ落ちた」 |
| 落ちる | 掛了 | テストが失敗する | 「seed 7 のが落ちてる。見ておくよ」 |
| シード | seed | 乱数シード | 「シードをちょうだい。もう一回流してみる」 |
| カバーできている | cover 到 | カバレッジで測れている | 「オーバーフローのケースがカバーできていない」 |
| 波形をダンプする | dump 波形 | デバッグのためにシミュレーションの波形を保存する | 「波形をダンプして見ればわかるよ」 |
| コーナーケース | corner case | めったに起きない境界の状況 | 「`LEN` が 0 のコーナーケースはテストした？」 |

## タイミングとバックエンド

| 言い回し | 台湾のチームでは | 意味 | 例文 |
|---|---|---|---|
| タイミングを閉じる | 收 timing | タイミング違反がなくなるまで直す | 「バックエンドはまだタイミングを閉じているところだから、ネットリストは触らないで」 |
| バイオレーション | violation | 違反 | 「setup のバイオレーションがまだ 200 本ある」 |
| slack が大きく負ける | slack 爆了 | slack が負で、しかも大きく足りない | 「このパスは 0.3 ns も負けている」 |
| 一段切る | 切一刀 | パイプラインを 1 段入れる | 「乗算と加算で長すぎるから、真ん中で一段切ろう」 |
| hold バッファを入れる | 補 hold buffer | 遅延用のバッファを入れて hold を直す | 「CTS が終わってから hold バッファを入れよう」 |
| P&R、APR | P&R、APR | 配置配線 | 「今回の P&R は一晩かかった」 |
| 混んで通らない | 塞爆 | 混雑して配線が通らない | 「MAC アレイの横がぎちぎちで通らない」 |
| RC 抽出 | 抽 RC | 寄生抽出 | 「RC を抽出したら、timing がまた悪くなった」 |
| クリーン | clean | 確認して違反がまったくない | 「LVS がやっとクリーンになった」 |
| ウェイブする | waive 掉 | ウェイバーの一覧に入れる | 「`LEN` は `START` より前に固定されるから、この CDC はウェイブしていい」 |

## チップが戻ってから

| 言い回し | 台湾のチームでは | 意味 | 例文 |
|---|---|---|---|
| サンプルが戻ってきた | 樣品回來了 | 最初のチップが実験室に届いた | 「サンプルは来週戻るから、ボードを先に用意しておいて」 |
| 立ち上げる | 點亮 | 初めて電源を入れ、基本の機能を確かめる | 「初日に立ち上がった。PLL もロックした」 |
| シュムーを取る | 跑 shmoo | 電圧と周波数の動作範囲を測る | 「まずシュムーを取って、低電圧の境界がどこかを見よう」 |
| 回避、ワークアラウンド | 繞過、workaround | ハードウェアの誤りをファームウェアやソフトウェアで避ける | 「この版はファームウェアで回避して、A1 で直そう」 |
| メタルフィックス | metal fix | メタル層だけを変える修正 | 「このバグはメタルフィックスで済む。全部作り直す必要はない」 |
| フルリスピン | full respin | いちばん下の層からすべてのマスクを作り直す | 「トランジスタの層まで変えるなら、フルリスピンしかない」 |
| A0、A1、B0 | A0、A1、B0 | ステッピング | 「A2 でまた直すなら、メタルのマスクを 3 枚替えるだけで済む」 |
